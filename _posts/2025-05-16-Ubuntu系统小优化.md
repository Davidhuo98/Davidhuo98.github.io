# Ubuntu系统小优化

**版本选择**
以前的版本可能会出现与windows双系统的情况下，在grub开机菜单无法正确引导进入windows的问题，现在的ubuntu24.04.3 LTS 已经解决了这个问题，比较稳定了，推荐下载这个版本：
https://releases.ubuntu.com/24.04.3/

在 Ubuntu 中启用“以管理员身份打开”选项
1.打开终端

首先，通过按键盘上的Ctrl+Alt+T组合键或从应用列表中搜索来打开终端。

2.安装nautilus-admin

当终端打开时，运行下面的命令:
`sudo apt install nautilus-admin`

3.重启文件管理器

退出所有文件管理器窗口，并输入一下命令:
`nautilus -q`

**在Ubuntu 中让应用程序显示在屏幕中央**
1.安装GNOME Tweaks 工具进行管理
`sudo apt install gnome-tweaks`

2.从应用列表中找到“优化”，并打开
![image](https://img2024.cnblogs.com/blog/3599182/202508/3599182-20250813172737992-83178461.png)

3.点击窗口左侧菜单栏，打开相应开关即可，此外还可以进行别的设置
![image](https://img2024.cnblogs.com/blog/3599182/202508/3599182-20250813172756708-1108010971.png)

**永久修改主机名**
1.方法一：修改配置文件，直接把名称写入即可，然后重启设备
`sudo vim /etc/hostname  #修改主机名 `
![image](https://img2024.cnblogs.com/blog/3599182/202508/3599182-20250813172857280-1532626638.png)
2.方法二：图形界面修改，使用键盘上下左右和TAB键进行选择修改，然后保存，重启后生效
`nmtui #打开图形界面`
![image](https://img2024.cnblogs.com/blog/3599182/202508/3599182-20250813172923451-1613313064.png)

**让Ubuntu和Windows10双系统时间同步**
在Ubuntu系统中，命令行输入：
`sudo apt-get install ntpdate               //在Ubuntu下更新本地时间`
`sudo ntpdate time.windows.com`
`sudo hwclock --localtime --systohc			//将本地时间更新到硬件上`
然后重启进入Windows，初次重启可能时间依然不同，但是在Windows调整一遍后，再随意切换时间就同步了。

如果找不到hwclock命令，则先运行以下命令进行安装：
`sudo apt-get install util-linux`
